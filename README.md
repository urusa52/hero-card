# 우리는 아직 『 』입니다 (We Are Still Untitled)

미완의 영웅들을 뽑는 확률까지 직접 설계하고, 그들로 이야기(족보)를 완성해
"잊히기 전에 다시 읽히게 하는" 로그라이크. — **M1 프로토타입**

## 실행

정적 파일만으로 동작합니다 (서버/외부 API 없음). ES 모듈을 쓰므로 로컬 실행 시 간단한 서버가 필요합니다.

```bash
# 방법 1
python3 -m http.server 8000   # → http://localhost:8000

# 방법 2
npx serve .
```

GitHub Pages에 저장소를 배포하면 링크 클릭만으로 플레이 가능합니다.

## 플레이 방법 (M1)

1. **설계** — 서고의 영웅을 캐스팅 계약서(풀)에 넣고, 슬라이더로 확률을 배분 (합 100%)
2. **호출** — 제한된 횟수 안에서 뽑기. 손패가 쌓임
3. **선언** — 성립한 족보(빛나는 항목)를 선언해 반향 획득. 쓰인 카드는 소모
4. 목표 반향 달성 → 다음 장. 8장을 완성하면 빈 『 』가 채워집니다

## 구조

```
src/
├── core/     eventBus(모듈 간 통신) · store(단일 상태)
├── logic/    gacha · poolBuilder · yaku · scoring · round  ← 전부 순수 함수
├── render/   hud · pool · draw · modal                     ← 상태 읽기 전용
├── input/    controls (DOM 이벤트 → 의도 이벤트)
└── data/     balance · cards · yaku                        ← 모든 수치는 데이터에
```

- 상태 변경은 `store.update()` 한 경로로만
- 족보/밸런스는 JSON — 코드 수정 없이 추가·조정 가능
- 로직이 순수 함수라 브라우저 없이 테스트/시뮬레이션 가능
